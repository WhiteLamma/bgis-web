# Responsive artwork

Generated with the built-in imagegen tool using the existing text-free desktop hero as the style reference. Converted to WebP for delivery; the original desktop hero is retained.

## Phone landing page

Asset: `public/images/bg-saar-hero-mobile-v1.webp` (941 x 1672).

Prompt: Create a new portrait 9:16 mobile website background matching the warm illustrated Indian Gurukula courtyard, cream parchment, sandstone arches, forest teal, sage leaves and peacock accents. Leave the upper 57% light ivory and quiet for real HTML text and a login button, with thin leafy corners and subtle arches at the edges. In the lower 43%, group one kind Indian teacher and four schoolboys learning with books and a tablet, wearing cream uniforms with green and saffron borders. Keep all faces in the lower half and visible on a narrow screen. Fill the portrait canvas coherently. No text, buttons, logo or watermark.

## Desktop login page

Original asset: `public/images/bg-saar-login-desktop-v1.webp` (1672 x 941). Superseded by the library-veranda v2 below; retained as design history.

Prompt: Create a new wide 16:9 desktop login background in the same illustrated style: a detailed sandstone Gurukula courtyard with forest teal foliage, peacock accents, lotus plants, sunlit arches and a tree canopy. Detailed architecture fills the leftmost and rightmost 28%; keep a quiet continuous light ivory central 40% for the real school crest and login form. A teacher and two schoolboys reading sit small in the lower left. Tree branches frame the top corners, with plants and tiled courtyard along the bottom. Warm morning light. A distinct scene without a giant Krishna silhouette. No form, UI, text, logo or watermark.

## Selection

The landing page uses the portrait asset at widths up to 900px and on portrait viewports. Wider landscape screens use the original desktop image. Login uses the original app background up to 900px and the new courtyard above that width. All copy, logos and controls remain separate HTML elements.
